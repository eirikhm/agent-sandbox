# agent-sandbox

A sandbox repository for experimenting with agents.

## Overview

This project is a work in progress. It currently serves as a space to prototype
and test ideas around autonomous and AI-powered agents.

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/eirikhm/agent-sandbox.git
   cd agent-sandbox
   ```
2. Explore the code and start building.
