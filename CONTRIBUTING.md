# Contributing

Thanks for your interest in contributing! This document is a stub and will be expanded.

## Getting Started

1. Fork the repository and clone your fork.
2. Create a branch for your change: `git checkout -b my-feature`.
3. Make your changes and commit them with a clear message.
4. Push your branch and open a pull request.

## Reporting Issues

Please open an issue describing the problem, including steps to reproduce.
